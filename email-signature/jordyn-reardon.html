Copied. Now paste it into Outlook.

New Outlook, Outlook on the web

  1. Settings (gear) > Account > Signatures > New signature.
  2. Click in the signature box and paste (Ctrl+V or Cmd+V). Save.
  3. Pick it as the default for new messages and replies.

Classic Outlook for Windows

  1. File > Options > Mail > Signatures > New.
  2. Paste into the edit box and click OK. The logo and icons show their still first frame here; people using new Outlook, Apple Mail, Gmail and phones see the animation.

Outlook for Mac

  1. Outlook > Settings > Signatures > +.
  2. Paste, name it, and close the window to save.
